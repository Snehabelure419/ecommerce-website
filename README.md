# 🛒 ShopEasy - E-Commerce Website

A modern and responsive E-Commerce Website built using HTML, CSS, and JavaScript. The project simulates an online shopping experience with product browsing, search functionality, category filtering, shopping cart management, and local storage support.

## 🚀 Live Demo

https://snehabelure419.github.io/ecommerce-website/





---

## ✨ Features

* Responsive Design
* Modern User Interface
* Product Search Functionality
* Category Filtering
* Add to Cart
* Shopping Cart Sidebar
* Product Ratings
* Discount Badges
* Local Storage Support
* Mobile Friendly Layout
