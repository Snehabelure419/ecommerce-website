# 🛒 ShopEasy — E-Commerce Website

### A Modern, Responsive & Interactive Online Shopping Experience

ShopEasy is a responsive e-commerce frontend application built using **HTML5, CSS3, and JavaScript (ES6+)**. It simulates an online shopping experience with product browsing, search, category filtering, shopping cart management, and browser-based data persistence.

Explore the live demo to experience the interface and its shopping features.

## ✨ Features

- 📱 **Responsive Design** — Adaptable layouts for desktop, tablet, and mobile devices.
- 🎨 **Modern User Interface** — Clean styling for a smooth browsing experience.
- 🔍 **Product Search** — Find products using search functionality.
- 🗂️ **Category Filtering** — Browse products by category.
- 🛍️ **Add to Cart** — Add products to the shopping cart.
- 🛒 **Shopping Cart Sidebar** — Review selected products in a dedicated panel.
- ⭐ **Product Ratings** — Display product ratings.
- 🏷️ **Discount Badges** — Highlight discounted products.
- 💾 **Local Storage** — Preserve supported shopping cart data across page reloads in the same browser.
- ⚡ **Interactive UI** — Update interface elements using JavaScript and DOM manipulation.

## 🚀 Getting Started

Run ShopEasy locally in a few simple steps.

### Prerequisites

- A modern web browser.
- Visual Studio Code (optional).
- Live Server extension (optional).

### 1. Clone the Repository

```bash
git clone https://github.com/Snehabelure419/ecommerce-website.git
```

### 2. Navigate to the Project Folder

```bash
cd ecommerce-website
```

### 3. Launch the Website

Open `index.html` in your browser, or open the folder in Visual Studio Code and select **Open with Live Server**.

No package installation or backend configuration is required for this frontend version.
